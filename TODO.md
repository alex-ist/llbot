# Roadmap

This document tracks planned improvements for LLBot. Priorities may change as the project evolves.

## Pronunciation and audio

- [ ] Evaluate an offline text-to-speech provider, such as Kokoro, for word and sentence audio.
- [ ] Make speech synthesis providers configurable.
- [ ] Improve error handling and usage-limit handling for external speech services.

## Learning experience

- [ ] Improve onboarding for the Telegram Mini App.
- [ ] Allow learners to add new words directly from the Telegram Mini App.
- [ ] Add support for additional learning languages, starting with Serbian.
- [ ] Add a training mode that practices each target word within phrases instead of presenting it in isolation.
- [ ] Add richer learning statistics, including activity and answer history.
- [ ] Suggest adding words or another topic when a learner has too few cards available.
- [ ] Add more curated word sets, including professional vocabulary.
- [ ] Support links and dictionary lookup for individual words inside phrases.

## Word management and content

- [ ] Improve translation and example-generation prompts for ambiguous words and phrases.
- [ ] Make user language and training settings editable.

## Reliability and maintenance

- [ ] Add automated tests for training, word management, and pronunciation flows.
- [ ] Add log rotation and structured operational logging.
- [ ] Improve service health and usage monitoring.
